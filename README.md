# Matematik Özel Ders Sitesi

Bu proje, matematik özel ders hizmetlerini tanıtmak ve öğrenci/veli ile eğitmen arasında iletişim kurmak amacıyla geliştirilmiş bir web sitesidir.  
Site; ders içerikleri, hizmet tanıtımı ve iletişim bölümlerini içeren modern ve kullanıcı dostu bir arayüze sahiptir.

## Projenin Amacı
- Matematik özel ders hizmetini dijital ortamda tanıtmak  
- Öğrenci ve velilerin dersler hakkında hızlıca bilgi almasını sağlamak  
- Eğitmen ile kolay iletişim kurulmasına olanak tanımak  

## Kullanılan Teknolojiler
- Angular
- TypeScript
- HTML5
- CSS3
- JavaScript

## Özellikler
- Responsive (mobil uyumlu) tasarım  
- Tek sayfa uygulama (SPA) yapısı  
- Ders ve hizmet tanıtım bölümleri  
- İletişim ve yönlendirme alanları  

## Kurulum ve Çalıştırma

Projeyi yerel ortamda çalıştırmak için:

```bash
git clone https://github.com/kullanici-adi/matematik-ders-sitesi.git
cd matematik-ders-sitesi
npm install
ng serve
